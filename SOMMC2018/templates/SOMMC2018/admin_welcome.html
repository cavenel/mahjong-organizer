Mahj.OVH (Mahjong Organizer Virtual Hub) is an "all-in-one" toolbox for organizing Mahjong Tournaments.

List of features:

  • Import players, positions and schedule from a spreadsheet file.
  • Print player cards, table positions, etc.
  • Write scores during tournament.
  • Print scores.
  • Manage displays / projectors (show counter, show scores between rounds, show schedule, etc.)
  • Export EMA report

Note that this application is not in any way related to the European Mahjong Association.
