Classes you can target

A rule here beats the theme and the card format it is on, so .write-cell on its own is enough — no need to write a longer selector to make one stick.

.card — one whole card
.card-head / .card-main — header band, body
.accent-bar / .accent-2-rule / .accent-sep — the rules
.title-font / .player-name / .country
.grid-row / .col-label / .seat-cell
.wind, .wind.E|S|W|N — seat chips
.write-cell / .write-cell.total — writing boxes
.day-band — the day separator
.footer-url — the line at the card's foot
.opp-grid / .opp-cell / .opp-cell.me — back side
