# MCR scoring — one-page cheat sheet

## A. Enter each table's MiniPoints

1. **Filter** — press <kbd>/</kbd>, type the **table number** → shows just that table.
2. **Check the 4 player names** are correct (East / South / West / North).
3. Press <kbd>Tab</kbd> to jump into the first **MiniPoints (MP)** box.
4. **Enter the 4 MP**, one per seat (Tab moves seat → seat).

5. ✅ **Check the Sum:**
   - **`0`** = no penalties, or symmetrical penalties → correct.
   - **Negative** (`-10`, `-20`, …) = a penalty was applied → **leave the negative
     sum**, it is *not* an error. Just confirm it matches the penalty total.
6. ✅ **Check the left column pip 🟠→🟢:**
   - 🟠 **orange** = sending to the server.
   - 🟢 **green** = saved & synchronised.
   - **Always wait for green BEFORE moving to the next table.**
7. Press <kbd>Tab</kbd> or <kbd>/</kbd> to return to the filter → type the next
   table, or **clear the filter** to see all tables.

---

## B. Add the Score sheets

Once all tables have their MP in, fill a **score sheet** for each table.

![QR code to oemc2026.mahj.ovh/scan](screenshots/qr-scan.svg){ style="float:right; margin:0 0 .4em 1em;" }

### 📸 OCR (optional shortcut)

1. On your phone or tablet, **Scan the QR code** on the right.
2. Enter the **round** and **table** number.
3. Photograph the **whole sheet**: good lighting, the **full page** in frame, flat.

### Manual entry / review
1. Click **Score sheet** on the table's row (or click the table after an OCR scan).
2. For **every hand line**, fill: **Value** · **Win** (seat `1`–`4`) · **From** (seat `1`–`4`).
3. If **pre-filled by OCR**, check each cell. **The redder the cell, the less sure it was**: verify those first.
4. **Penalties?** Add them on the **last (Penalties) line**.
5. Confirm the score sheet's **MP sum matches** the MP you entered in step A.

### ✅ Finish
When everything is correct, tick **Validate score sheet** → the hands lock in.

## At a glance

| Step | Do | Check |
|---|---|---|
| **Filter** | <kbd>/</kbd> + table number | Right table shown |
| **Names** | — | 4 players correct |
| **MP** | <kbd>Tab</kbd>, enter 4 values | **Sum** = `0` (or negative if penalties) |
| **Save** | auto | **pip 🟢 green** before next table |
| **Sheet** | OCR scan *or* **Score sheet** button | Value / Win / From per hand; red = check |
| **Penalty** | last line of the sheet | MP sum matches step A |
| **Done** | tick **Validate score sheet** | hands locked |
